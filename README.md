# Vitae.Lp – Recuerdos Impresos

Sitio web de un emprendimiento de impresiones fotográficas y papelería: polaroids, fotos y cuadernos. Permite explorar los productos, configurarlos, armar un carrito y enviar el pedido por WhatsApp.

🔗 **Ver en vivo:** https://fedeacc.github.io/Pagina.Vitae-2.0/

## Funcionalidades

- **Catálogo y páginas de detalle** por producto, con navegación entre vistas sin recargar la página (History API) y breadcrumb.
- **Configurador de productos:** selección de tamaño, tipo y diseños, con cálculo de precio en tiempo real.
- **Carrito de compras** con cantidades editables y notificaciones (toasts).
- **Descuentos automáticos** por cantidad y por monto de compra, y **cupones** de descuento (porcentaje o monto fijo).
- **Pedido mínimo** validado antes de enviar.
- **Envío del pedido por WhatsApp** con el detalle del carrito armado automáticamente.
- **Diseño responsive:** menú hamburguesa y barra inferior en móvil, carrusel de productos arrastrable y slider de portada.
- Banner de novedades animado, galería y sección de testimonios.

## Tecnologías

- HTML5
- CSS3 (variables CSS, Grid, Flexbox, animaciones, media queries)
- JavaScript (vanilla, sin frameworks ni librerías)
- Google Fonts

## Estructura

Todo el sitio está en un único archivo, `index.html`, con los estilos y scripts incluidos.

## Cómo ejecutarlo

1. Cloná el repositorio: `git clone https://github.com/Fedeacc/Pagina.Vitae-2.0.git`
2. Abrí `index.html` en el navegador. No requiere instalación ni servidor.
